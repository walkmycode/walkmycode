Neat wrapping

A long line wraps under its own indentation, two columns in, so you can still see where each line starts. Never back at the left edge.

Indent guides

A quiet line for every level of nesting, in a colour per level. The block your cursor is in draws itself bright.

Coloured brackets

Each pair of brackets shares a colour by depth, so you can see which closes which. The pair around your block lights up.

Motion

The current-line band glides, guides draw down, brackets give a small pop. Off when your computer asks for less motion, or in Settings.

All four are on by default and each is a switch in Settings → Editor, beside line history and suggestions. The file's own lines are kept: nothing is reformatted, so line numbers still match citations, tours and git.
