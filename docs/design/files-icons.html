How a file finds its drawing
By what the file is, then its extensionA name or a folder says more than an extension: Dockerfile, .github/workflows/*, tests/, *.lock, README, LICENSE, .env* come first; then the extension; anything else is the plain page.
Code wears its language's colourOne code drawing, tinted: Rust orange, TypeScript blue, JavaScript yellow, Python steel blue, Go teal, C# purple… The drawing can be recoloured by design, and no language's logo is borrowed.
Folders with a job show ittests, docs, scripts, migrations, public and .github/workflows wear their drawing; every other folder is the folder.
Small and calm in the tree18 px by default (16 and 20 to try), without the ground shadow; a row's drawing lifts a little on hover. The whole drawing, 72 px, heads the open file, and 30 px leads each search result.
In the appfileIcon(path) beside fileKind in src/lib/fileTree.ts, tested like the drawings; FileTree.tsx draws it with the Drawing component; the kind chips keep working as they are.
