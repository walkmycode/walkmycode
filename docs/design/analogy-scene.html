For any lesson

    
From wherever the lesson came from to a scene, the same five steps

    

      
1 · the lessonAny source
A course folder (README + code), notes you pasted, a topic you asked for ("how does a mortgage work?"), or a lesson the professor wrote for you.

      
2 · the boardOne idea, one analogy
Each talk board already carries an everyday analogy, set in the UK, that extends the lesson's one picture.

      
3 · the kindThe professor picks a kind
From the shape of the idea: who has it, when and how long, in what order, what is on top, which is bigger. One kind per scene.

      
4 · the dataWrites it as data, checked
Names, places, steps, the real side (code, or the subject's own facts with where they came from). Checked like cleanScene does today: every step must agree with the real thing.

      
5 · the playerOne player draws every kind
Same headline, captions, X-ray, guess-first, rule card. Code lessons run their real example on this computer, so the output beside the picture is real.

One colour per idea
