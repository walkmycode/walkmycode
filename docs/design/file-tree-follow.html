What happens when the map, a trace or the guide lands on a file

  • Folders open down the path, one level every 70 ms; the rows they hold rise in.
  • A rail is drawn from the top folder down each level to the file (260 ms), and the path's folders turn gold.
  • The file becomes the beacon: a gold post grows, a wash sweeps across, the icon pings once.
  • The tree scrolls only if it must, and only enough to centre the file.
  • Each file on a trace keeps its number (1, 2, 3…), so the tree shows the whole path at once.
  • The path bar at the top spells out where the file is.

Speed

  • Opacity and transform only, plus one SVG stroke, so it all runs on the compositor.
  • Rows are virtualised: only what's on screen is built, so a 12,000-file workspace scrolls as fast as a small one.
  • A new reveal cancels the one still running.
  • With Reduce motion, everything still happens, but instantly.

Controls (panel header)

  • ◎ shows the open file.
  • ⇄ turns following on or off. When it's off, a ▲/▼ chip appears if the file is out of view.
  • ⊟ folds everything.
  • “Fold what's off the path” (optional) keeps only the path open.
