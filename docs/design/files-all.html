Every fileThe folder readers list every file's path, not only the code they read. Never node_modules, .git, build output (target, dist, .next…) or a real .env, same as now. Paths only: a file's text is read when it's opened.
KindsAn icon per kind: code (blue), docs (green: .md, .txt, LICENSE), config (orange), images (purple), lock and other files (grey). Files the map didn't draw are quieter, and hovering says “not on the map”.
SearchCtrl P, or / in the panel. Fuzzy over the whole path, ranked: consecutive letters, the file name over the folders, shorter paths first. Up to 200 results drawn; the count says how many matched.
MotionResults rise in, 22 ms apart; the selection bar slides; folders open with the rows rising in as today. Opacity and transform only, so 12,000 files stay smooth, and with motion off it just appears.
