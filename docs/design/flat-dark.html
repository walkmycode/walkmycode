Proposed · flat dark

What changes (dark theme only; Warm stays as it is)
  • One dark everywhere: page, side panels, cards, the map, the code, the Learn board, chat, inputs and menus are all #141414. Nothing is lighter or darker than anything else.
  • Thin borders separate things. Selected and active things (a file, a tab, a setting, a card) get a yellow edge or yellow text, never a lighter fill. Hover is a border, not a fill.
  • No gradient anywhere: no background glows, no board sheen, no wooden frame, no gradient text, no glowing selected cards, no shimmer on progress bars.
  • Patterns made with gradients go too: the map's dot grid and the stage's grid are plain; the progress ring is a flat ring.
  • No shadows: depth comes only from borders.
  • The yellow accent, and blue, green and pink for meaning (lanes, diffs), stay.
  • A test fails the build if a gradient comes back in the dark theme.
